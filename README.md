# iPhone Use PR #12: recorded Calendar report

This is the complete native HTML report used for the illustrations in https://github.com/zhongerxin/iPhone-use/pull/12.

Recorded October 10, 2026 on an iPhone 17 Pro simulator (iOS 26.5), with gpt-6.1-sol and Midscene 1.13.4-beta-20261010095145.0. It contains both the create/save/reopen phase and the edit/save/reopen phase under report_id `calendar-1-default`.

Download `calendar-report.html` and open it in a browser to inspect action details, recorded screens, and replay. This self-contained file needs no account or model connection to view. The test event was cleaned up after the run.

The report data was checked before publication: no access tokens, refresh tokens, authorization headers, or local user-directory paths occur in the recorded payload. Images show the dedicated simulator test event.
